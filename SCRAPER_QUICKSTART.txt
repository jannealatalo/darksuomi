WINDOWS TASK SCHEDULER (Recommended):
  1. Create C:\repo\darksuomi\run-scraper.bat:
     @echo off
     cd /d C:\repo\darksuomi
     python scraper-multi.py
     pause

  2. Task Scheduler → Create Basic Task
     - Name: Dark Suomi Scraper
     - Trigger: Daily at 2:00 AM
     - Action: run-scraper.bat

  3. Test: Right-click task → Run

GITHUB ACTIONS (CI/CD):
  1. Create .github/workflows/scrape-events.yml
  2. See SCRAPER_SETUP.md for content
  3. Push to GitHub
  4. Check Actions tab
